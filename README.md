# 昨日圆车

《昨日圆车》是一款原创中文策略塔防游戏。城市在“昨日失窃”后每天午夜失去前一天的记忆，玩家作为末代调度员，部署行者守住逆向行驶的圆车与城市残存的昨日。

## 当前内容

- 五个连续章节、25 个主线关卡与战前/战后剧情
- 19 名原创行者，10 人编队、招募与养成系统
- 拖拽选格、松手后滑动定向、撤退与再部署
- 物理/法术抗性、群体攻击、治疗、控制与技能技力
- 多类回收兽、三批敌潮、多入口与多守护点地图
- 四帧战斗动作、追踪弹道、技能特效和战斗音效

## 本地运行

需要 Node.js 22.13 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开开发服务器显示的地址即可开始游戏。

生产构建：

```bash
pnpm build
```

## 基本操作

1. 在大厅选择战斗副本并完成编队。
2. 接受调度后敌潮开始行动。
3. 从预备栏拖动行者到合法格子，松手后继续滑动选择方向；可随时取消部署。
4. 蓝色覆盖格表示攻击范围；技力满后，行者上方会出现紫红色“技能就绪”提示。
5. 点击场上行者可查看详情、释放技能或撤退。

## 世界观

“昨日失窃”后，城市每天午夜都会失去前一天的记忆；被夺走的过去在未来凝成“回收兽”。一列沿环城轨道逆向行驶的圆车保存残存记忆。玩家需要守住终点，但每取回一段昨日，也会失去自己更久以前的一段人生。

> 昨日值得被守护，但明日必须由放下昨日的人亲自抵达。
